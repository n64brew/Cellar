NetLib is the first online networking library created for use in homebrew N64 games using a flashcart's USB. To show off the library, three example ROMs are available:
1) A simple Hello World ROM that retrieves a message from the server
2) A 2-player game of Ultimate Tic Tac Toe
3) A realtime movement example showcasing how to implement clientside prediction and reconciliation

The ROMs require the usage of the NetLib Browser in order to play online. More information is available in the GitHub link below or the YouTube video above.
