UNFLoader (Universal N64 Flashcart Loader) is a USB debugging tool for flashcarts. The library comes with 7 example ROMs (4 for Libultra, 3 for Libdragon) that showcase library features. They require the use of a tool that follows the UNFLoader USB protocol to use.

The Libultra ROMs are:
1) A hello world print to USB
2) A showcase of the debugging library with a crash trace
3) A ROM that echoes back any text sent via USB
4) A showcase of the debugging library command system, allowing modification of the game state at real time.

The Libdragon ROMs are:
1) A hello world print to USB
2) A ROM that echoes back any text sent via USB
3) A showcase of the debugging library command system, allowing modification of the game state at real time.
