Pyoro64

Released: December 25, 2018
Authors: Buu342
Genre: Arcade
Age Rating: All
Tags: 1 Player, 2 Players, EEPROM Saves, Libultra, MPAL Console, NTSC Console, PAL Console, Source Code Available, Supports Accurate Emulator, Supports Inaccurate Emulator

Pyoro64 is a clone of a WarioWare minigame. It plays just like the original, but it has the addition of a two player mode.

Notably, the Pyoro64 ROMs were developed alongside some documents that cover how to use the official N64 SDK to make your first ROMs, using Pyoro64 as a practical example. The documents, however, remain unfinished.
